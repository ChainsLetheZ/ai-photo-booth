# Booth videos

The production interaction videos are stored here as browser-ready MP4 files:

- `new-left-idle.mp4` — newly supplied `1循环.mov`: left-side looped
  photographer pose.
- `02-arrival-once.mp4` — person enters frame: one invitation action.
- `03-gesture-loop.mp4` — waiting for the selected gesture: looped prompt.
- `right-exit-reverse.mp4` — the first part of the right-side entry clip,
  reversed so the companion naturally leaves to the right at shutter time.
- `04-capture-hold.mp4` — after gesture recognition: one camera action that
  ends on a held camera pose while the QR is prepared.

The app will load them from `/videos/` once they are embedded.
